# Edy.AI.Studio 🎨

Edy Studio 主页源码仓库 — 粒子特效画廊与 AI 作品集。

## 在线地址

| 平台 | 地址 |
|------|------|
| GitHub Pages | https://michoney.github.io/edystudio/ |
| CNB 镜像 | https://cnb.cool/edyai.cc.cd/edystudio |

## 内容

- **gallery/** — p5.js 粒子特效画廊（gallery.html 主页 + 每个特效独立目录）
- **benchmark/** — 马哥验机：手机性能检测工具
- **tools/** — AI 交互工具集
- **video/** — AI 视频作品
- **camp.html / recruit.html** — AI 实战训练营入口
- **github-weekly.html** — GitHub 每周热门趋势图

## 技术栈

- HTML / CSS / JavaScript（纯静态站点，零依赖）
- p5.js / Three.js（粒子特效）
- GitHub Pages 部署，支持国内镜像

## 本地预览

```bash
cd edystudio
python3 -m http.server 8080
# 打开 http://localhost:8080
```
