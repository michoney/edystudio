# 施瓦西黑洞 · Schwarzschild Black Hole

实时广义相对论黑洞渲染器。纯 WebGL2 单页面应用，无任何依赖、无需安装、可离线运行。

![预览](index.html)

## 特性

- **真实引力透镜**：逐像素积分光子测地线，事件视界、光子球、爱因斯坦环、吸积盘上下缘翻折像全部自然呈现
- **相对论多普勒束射**：吸积盘一侧因朝向观察者运动而增亮偏蓝（Interstellar 式不对称）
- **引力红移**：越靠近视界，盘面越暗越红
- **开普勒差速旋转**的湍流吸积盘（ISCO 内缘 3 rs）
- 程序化星空 + 银河带背景，ACES 色调映射
- 触摸/鼠标轨道相机、双指缩放、自动环绕、自适应分辨率（手机流畅）

## 运行

### 电脑
直接双击 `index.html` 用 Chrome / Edge / Firefox 打开即可。

### 手机
任选其一：

**方案 A · 局域网访问（推荐，iPhone 同样适用）**
```bash
cd SchwarzschildBlackHole
python -m http.server 8000
```
手机浏览器访问 `http://<电脑局域网IP>:8000`

**方案 B · 直接拷贝**
把整个 `SchwarzschildBlackHole` 文件夹拷到手机，用安卓浏览器的"打开本地文件"选择 `index.html`。
（iOS 的文件预览不执行 JS，请用方案 A）

## 物理说明

采用史瓦西度规下零测地线的精确形式。取 `rs = 2GM/c² = 1` 归一化，
光子轨迹满足 Binet 方程 `d²u/dφ² + u = 3Mu²`，等价三维形式：

```
a⃗ = −(3/2)·h²·r⃗/r⁵ ，  h² = |r⃗ × v⃗|² （守恒角动量）
```

- 事件视界：r = 1 rs
- 光子球：r = 1.5 rs（阴影边缘 ≈ 2.6 rs，由 √27/2 rs 给出）
- ISCO（盘内缘）：r = 3 rs；圆轨道速度 β = √(rs/2r)
