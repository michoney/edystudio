Miora —— 腾讯出品的「有记忆的」Agentic 创意工作室 Miora · The Agentic Creative Studio with Memory by Tencent
一句话 Brief 进去，多模态成品（图片、视频、UI、3D）出来，而且越用越懂你。

Miora 是腾讯设计团队推出的 AI 原生创意工作室，不是普通的 AI 画图工具，而是一个真正能「记住你」的创意合伙人。

Agent Memory · 核心亮点

大多数 AI 工具每次对话都失忆。Miora 会记住你的品牌色、语气、审美偏好、创作规则，甚至「绝对不要做的事」。用得越久，越像你自己的风格。

Specialist Network · 创意专家团队

直接调用不同领域的专家 Agent：Brand、Storyboard、Illustration、UI/UX、Video、3D……它们协作完成完整项目，而不是单一生成一张图。

Brief → Delivery · 一站式成品

在同一个可编辑画布上，从概念、分镜、插画到视频、界面、3D 资产，全部搞定，产出可直接用于生产的素材包。

Skills + Community · 社区生态

把好用的工作流保存成可复用的「Skill」，下次一键调用。还能分享到社区，或从 Inspiration Box 里发现别人的优质流程。

简单使用方法

  • 打开官网 https://miora.design/
  • 点击 START CREATING
  • 在画布上直接输入 Brief（例如：「为一款黑暗奇幻 RPG 设计三名战士角色概念」）
  • 系统自动读取你的记忆风格，调动相关专家 Agent 开始工作
  • 在画布上迭代修改，导出多模态成品
  • 满意的工作流可保存为 Skill，下次复用

适合：独立创作者、设计师、内容团队、游戏概念设计师、品牌方……一个人就能当整个创意工作室。

Miora 的定位很清晰——不是一次性生成工具，而是长期陪伴你、越用越懂你的创意工作室。喜欢做视觉、品牌、内容的朋友强烈建议亲自试一下。

OpenHands —— 开源 AI 软件工程师平台 OpenHands · Open Source AI Software Engineer Agent Platform
不只是代码建议，而是能像初级工程师一样自主完成完整开发任务的 AI Agent 平台。

OpenHands（前身是 OpenDevin）是目前最受欢迎的开源 AI 编码 Agent 平台之一。它真正能像初级工程师一样自主完成完整开发任务：看代码、改代码、跑终端、开 PR、修漏洞、处理 Issue……

现在主推的入口是 Agent Canvas——一个可自托管的「AI 工程团队控制中心」。

它能做什么

  • 真正动手写代码：规划任务、修改代码库、运行测试、提交 PR
  • 自动化工程工作流：自动分解 GitHub Issue、审查 PR、修安全漏洞、处理 Linear/Jira 工单
  • 多 Agent 后端切换：本地、Docker、云端、企业 VPC 随便切换，不中断工作
  • 深度集成工具：原生支持 GitHub / GitLab、Slack、Linear、Notion、CI/CD 等 70+ 工具
  • 模型无关：支持任意 LLM，也可直接使用 Claude Code、Codex、Gemini 等 ACP 兼容 Agent
  • 安全可控：本地/自托管运行，数据不出你的环境，支持沙箱隔离

把「写代码 + 修 Bug + Code Review + 处理工单」这些日常工作，交给 AI Agent 全自动完成。

简单使用方法

方式一：最快速本地启动（推荐先试）

需要 Node.js 22.12+ 和 uv：

# 安装
npm install -g @openhands/agent-canvas
agent-canvas

# 浏览器打开
http://localhost:8000

方式二：Docker 沙箱（更安全，推荐日常使用）

export PROJECTS_PATH="$HOME/projects"
mkdir -p "$PROJECTS_PATH" "$HOME/.openhands"

docker run -it --rm \
  -p 8000:8000 \
  -v "$HOME/.openhands:/home/openhands/.openhands" \
  -v "${PROJECTS_PATH}:/projects" \
  ghcr.io/openhands/agent-canvas:1

访问 http://localhost:8000 即可。

适合谁用

  • 想让 AI 真正「干活」而不是只聊天的开发者
  • 希望自动化 Code Review、Issue 拆解、漏洞修复的团队
  • 需要自托管、数据不出内网的企业用户
  • 想搭建自己的 AI 工程流水线的人

核心组件 MIT 开源，社区活跃（81k+ Star），可本地跑、可上云、可企业私有化。感兴趣的直接去 GitHub 或官网试试，5 分钟就能跑起来。
