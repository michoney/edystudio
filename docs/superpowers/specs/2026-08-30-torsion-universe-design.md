# 旋转扭紧宇宙交互模型设计规格

## 1. 目标

在 EdyStudio 中新增一个独立的三维交互实验，用高密度科研终端的视觉语言呈现用户提出的宇宙原理：宇宙的坍缩不是各方向把物质像纸团一样压向一个几何点，而是时空与物质在旋转中产生层间角度差，像拧毛巾一样逐步扭紧。当扭转密度达到有限上限时，中央的最大扭转面触发 Big Bounce，时空反向解旋并进入新一轮膨胀。

页面是“概念宇宙模型”的交互可视化，不将未经实验验证的机制陈述为已确立的物理事实。

## 2. 参考与定位

- 交互骨架参考 EdyStudio Model Products 中的“AI 大脑运算场”：全屏三维画布、拖拽旋转、滚轮缩放、模式切换、实时指标。
- 视觉密度参考用户提供的三张截图：巨型环形结构、放射状高密度光轨、蓝紫青节点群、底部多栏仪表盘、深色科研终端。
- 不复制参考截图中的品牌、文案、具体数据或界面；只采用其高密度科学可视化的表达方式。

## 3. 信息架构

页面路径为 `torsion-universe/`，并在根目录 `models.html` 新增一张模型产品卡片。页面包含两个可切换的观察模式：

1. `01 宇宙循环场`
2. `02 扭转结构分析`

模式切换不重新加载页面。三维摄像机、可视化对象、标注和仪表数据在同一场景中平滑过渡。

## 4. 画面一：宇宙循环场

### 4.1 主体

中央为一个巨型、可观察内部的环形/双锥形时空截面。三维网格由纬线环和经线组成，线条密度足以形成宏大尺度，但在手机上不得聚成不可辨认的白块。

宇宙的一个完整循环是：

`EXPANSION → DECELERATION → ROTATION BUILDUP → TORSIONAL COLLAPSE → MAXIMUM TORSION → BIG BOUNCE → COUNTER-ROTATION → NEW EXPANSION`

### 4.2 形变规则

- 膨胀阶段：环的半径和纵向长度增大，网格疏展，主色为蓝白和青色。
- 减速阶段：尺度增长减慢，层间角度差开始出现。
- 扭转坍缩：外层和内层使用不同角速度；越靠近中央，扭转梯度越高。结构同时收腰和旋转，不允许仅使用等比缩放表现坍缩。
- 最大扭转：中央保留有限半径的环形或带状临界面，不收缩成无尺寸的点。
- Big Bounce：临界面短暂提亮为白金色，释放一次沿网格传播的相位波；旋转方向平滑反转，不使用突然切镜。
- 反向解旋：时空网格在相反方向上松开，新一轮膨胀的光轨从中央向外扩散。

### 4.3 光轨

数千条短长不一的光轨沿时空层流动。光轨必须遵从当前网格的旋转与曲率，不是与模型无关的随机背景线。膨胀时向外流动，坍缩时向中央汇聚，反弹时发生方向反转。

## 5. 画面二：扭转结构分析

此模式将宏观宇宙分解为若干个蓝、青、紫色的发光时空区域。区域之间使用具有方向的轨迹线连接，表示物质、能量和角动量的传递。

- 中央节点是 `MAXIMUM TORSION SURFACE`。
- 用户可选择区域，查看旋转方向、相对扭矩、局部曲率和临界距离。
- 可切换外层、中层和核心层的可见性，以便观察内部的反向旋转。
- 不表现为 AI 神经节点工作流；所有名称和数据都围绕扭转宇宙概念。

## 6. 交互与运镜

- 拖拽：旋转三维视角。
- 滚轮/双指：缩放。
- 播放控制：播放、暂停、重置，速度为 `0.25× / 0.5× / 1× / 2×`。
- 时间轴：可拖动到循环中的任意阶段，松手后从当前状态继续播放。
- Big Bounce 慢动作：位于画面一的专项控制，自动定位至临界前并降速播放。
- 模式切换：摄像机在宏观环形结构和结构分析视图之间平滑飞行，不闪白、不重载。
- 移动端：首屏仍以三维主体为焦点，指标板折叠为可滑出底栏，不让文字遮挡模型。

## 7. 视觉系统

- 基底：近黑色，带非常轻微的蓝色深空雾化，不使用紫色渐变网页背景。
- 膨胀：冷白、青蓝。
- 扭紧：紫、洋红过渡到橙红。
- 反弹：短暂白金色高亮，随后回到青蓝。
- 字体：标题使用窄体或几何无衬线，指标使用等宽字体；中文优先使用本地可用的高可读字体回退链。
- 界面密度：桌面端底部为多栏科研仪表盘；主体区只保留必要标注，防止层级混乱。
- 不添加水印、第三方标识或“AI 生成”标签。

## 8. 数据与仪表盘

页面运行时实时计算并显示用于该概念模型的归一化数据：

- `CYCLE AGE` 循环年龄
- `EXPANSION FACTOR` 膨胀系数
- `ANGULAR VELOCITY` 角速度
- `TORSION DENSITY` 扭转密度
- `CURVATURE INDEX` 曲率指数
- `PHASE` 当前阶段

宇宙年龄可用“亿年”显示，但模拟的半周期与临界点是用户概念模型参数，页面要用 `CONCEPTUAL PARAMETER` 标记，不伪装成观测常数。

## 9. 技术架构

- 独立静态目录：`torsion-universe/`。
- 主页：`torsion-universe/index.html`。
- 样式：`torsion-universe/css/style.css`。
- 场景入口：`torsion-universe/js/main.js`。
- 几何生成、循环状态、仪表数据和界面控制分离为边界清晰的模块，避免单文件承担全部职责。
- Three.js 负责 WebGL 场景，使用 `BufferGeometry` 、实例化或合并几何减少 draw calls。
- 动画使用一个可确定求值的归一化循环参数 `phase ∈ [0,1]`；自动播放和时间轴都只修改该状态，避免两套动画逻辑偏离。
- 无后端依赖，不发送用户数据，可随 EdyStudio 直接发布至 GitHub Pages 和 Cloudflare Workers。

## 10. 性能与降级

- 桌面端目标：主流独显/集显下保持流畅交互。
- 移动端根据屏幕尺寸和设备像素比降低网格、节点和光轨数量，但不删除两个观察模式。
- 当 `prefers-reduced-motion: reduce` 启用时，默认暂停自动循环，保留时间轴手动观察。
- WebGL 初始化失败时显示有设计的静态结构图和概念说明，不留空白页。

## 11. 验收标准

1. 访问 `torsion-universe/` 时无 JavaScript 报错，三维场景可正常运行。
2. 用户可在两个观察模式之间切换，且过渡不重载页面。
3. 循环画面明确区分膨胀、扭紧、最大扭转、反弹和反向解旋。
4. 坍缩是层间差速旋转与收腰的组合，不是对整个模型做等比缩小。
5. 中央临界结构保持有限尺寸，不变成几何点。
6. 时间轴、播放/暂停、速度和 Big Bounce 慢动作控制可用。
7. 桌面端的底部仪表盘与三维画面数值同步；移动端控件不遮挡主要结构。
8. `models.html` 存在可访问新实验的卡片，现有产品入口不受影响。
9. 桌面端和手机窄屏均通过基本交互、可读性与性能检查。

## 12. 范围边界

第一版不包含：

- 真实宇宙观测数据接口；
- 用户账号或云端数据保存；
- VR/WebXR 模式；
- 将概念参数拟合成宇宙学测量结果；
- 视频导出或高清离线渲染。

这些能力只能在第一版交互与性能通过验收后单独评估。
