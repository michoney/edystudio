# 一方水世界 · 2026-10-16

原生 WebGL2，可直接打开 index.html，无外部模型、字体或图片依赖。

- 地形、岩层、植被和双桅海盗船均为程序化几何。
- 水体使用 192² 交错网格浅水方程：先更新重力驱动的水平流量，再通过通量散度更新水位；封闭边界、地形挡水、湿干处理。
- 这是高度场浅水模型，不模拟三维翻卷浪、油水两相或飞溅液滴。
- 拖动带来冲量；倾斜滑杆改变等效重力；回正后水位在阻尼作用下恢复。水面、侧壁和船使用同一模拟结果。
- 船读取实际高度和法线作浮力响应。
- 浮点 FBO 需要 WebGL2 与 EXT_color_buffer_float。

操作：移动鼠标拨水；拖拽环绕；滚轮缩放；控制面板调海风、倾斜和光线；↶ 回正复位。

验证：test/fluid-validation.mjs 在本机 Chrome 实际 GPU 运行。静水水位为 0；倾斜使两侧水位变为约 -3.44/+3.35；该轮总水量相对误差 7.45e-9；回正后动能下降；船姿态和 GL 状态正常。预览截图见 预览/流体修正-*。
