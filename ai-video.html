// TRIGGERS「文章转图解视频」「手绘 B-roll」「Seedance 出图」

Workflow · 两种使用方式

// FULL PIPELINE · 一键全流程

  1. 说「从头帮我做一条视频」
  2. space-video 总控接管
  3. 逐环节调用子技能
  4. 文件落盘交接
  5. 成片后自动复盘

// SINGLE SKILL · 单技能触发

  1. 说「帮我想视频选题」→ topic
  2. 说「写口播脚本」→ script
  3. 说「剪这条口播」→ edit
  4. 说「做个动效 B-roll」→ broll
  5. 说「做封面」→ cover
